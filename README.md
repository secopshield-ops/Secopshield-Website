# SecOpShield Enterprise Website

Enterprise-grade cybersecurity platform website built with React, TypeScript, Tailwind CSS, and Framer Motion.

## 🚀 Quick Start

### Prerequisites
- Node.js 16+ 
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🎨 Design System

### Colors
- **Primary**: Blue (#2563EB) & Cyan (#06B6D4)
- **Dark BG**: #0a0e27
- **Dark Card**: #1a1f3a
- **Status**: Success (#10B981), Warning (#F59E0B), Danger (#EF4444)

### Typography
- **Font**: Inter
- **Sizes**: Heading LG (3.5rem), MD (2.25rem), SM (1.5rem)
